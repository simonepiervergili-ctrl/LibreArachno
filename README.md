Since it's been 15 years since the very well-known Arachno SoundFont by Arachnosoft - Maxime Abbey is released, I've decided to make a libre version of Arachno SoundFont, calling it "LibreArachno", some instruments are imported from Aspirin DX Fairytale Edition and Crisis DX, and I will also be recreating Arachno patches as well, so stay tuned!!!

[Source Files](https://github.com/NeoSoundFonts/LibreArachno-Source-Files)
